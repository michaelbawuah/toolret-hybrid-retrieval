# Efficient Tool Retrieval for LLM Agents

Independent reproduction and extension of **ToolRet** (ACL 2025), with a focus on
lightweight sparse+dense hybrid retrieval, hard-negative mining, reranking, and
accuracy/latency trade-offs.

> Status: **Milestone 1 complete — independent BM25 + evaluation harness**

## Research question

Can a lightweight multi-stage retrieval pipeline combining sparse retrieval,
dense retrieval, hard-negative training, and compact reranking improve tool
retrieval quality while keeping latency low?

## Why this repository is independent

The official ToolRet code is the reference benchmark. This repository deliberately
reimplements core retrieval and evaluation components so that every result can be
explained, tested, and modified rather than treated as a black box.

## Data contract

Corpus JSONL:

```json
{"id":"tool_1","name":"weather_forecast","description":"Get a weather forecast.","parameters":{"city":{"type":"str"}}}
```

Query JSONL is compatible with the key structure shown in ToolRet examples:

```json
{"id":"query_1","query":"Weather tomorrow in Ithaca?","labels":[{"id":"tool_1","relevance":1}]}
```

## Run Milestone 1 without installing anything

From the repository root:

```bash
PYTHONPATH=src python scripts/run_bm25.py \
  --corpus data/sample/corpus.jsonl \
  --queries data/sample/queries.jsonl \
  --k 1 3 5
```

The included sample is a smoke test, **not a research result**.

## Run tests

```bash
PYTHONPATH=src python tests/run_tests.py
```

We will distinguish:
